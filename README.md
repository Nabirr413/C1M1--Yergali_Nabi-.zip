## Project Overview
This project contains a C programming implementation that performs basic statistical analysis on a predefined dataset of 40 unsigned char elements.

### Functions Implemented:
* `print_statistics()`: Prints the calculated minimum, maximum, mean, and median values.
* `print_array()`: Formats and prints the array values to the command line.
* `find_median()`: Finds the median value of the dataset (rounded down).
* `find_mean()`: Computes the arithmetic mean of the dataset (rounded down).
* `find_maximum()`: Finds and returns the maximum value in the array.
* `find_minimum()`: Finds and returns the minimum value in the array.
* `sort_array()`: Sorts the array in descending order (largest to smallest).
